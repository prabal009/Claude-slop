A few things worth knowing about this demonstration.

Is this a real print-shop service?

The simulation on this page is browser-local and uses fictional jobs. The connected PrintQ Student and Shopkeeper portals use real accounts, a shared server queue, and private document storage (with an optional local demo mode). No payment processing is included.

Does this page change my portal queue?

No. The landing-page queue is an isolated, memory-only simulation. Preview, confirmation and reset affect only the example here and never modify the connected Student or Shopkeeper workspace.

Is queue optimization powered by AI?

No. It uses deterministic rules and transparent time estimates. The portal compares eligible jobs, protects applicable fairness constraints and asks for confirmation before changing order. A shorter wait for one job can mean a longer wait for another.

Will it print or scan on my device?

Physical printing uses your browser and device capabilities; queue status does not prove a print completed. Camera pickup scanning needs permission and a supported secure context. You can also enter a pickup token manually.

Can I open this page offline?

Yes. This single HTML file includes its own styles, visuals and demonstration. To use the connected Student and Shopkeeper portals, serve the project with npm run dev. The landing page makes no external requests and saves no job data.
